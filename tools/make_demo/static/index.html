操作说明
所有视角与渲染参数都在浏览器里实时可调，不需要重新推理。

      
    

    

      
视角

      
    
        
  • 左键拖拽 旋转，右键拖拽 平移，滚轮 缩放，双击 把旋转中心放到点云上。
    • 
        
  • 斜视 / 俯视 / 沿街 预设适合城市演示；环绕 自动旋转。
    • 
        
  • 跟随 让相机沿预测航迹飞行，形成无人机视角的巡检动画。
    • 
      

      
时间轴

      
    
        
  • 拖动顶部滑杆或点击右侧航点缩略图，查看任意航点完成时的重建结果。
    • 
        
  • 播放时新航点的点云按“近→远”逐步补全，黄色高亮当前新增区域。
    • 
      

      
显示

      
    
        
  • RGB / 语义 / 双栏对比；类别可单独开关；深度置信和分割置信可实时过滤。
    • 
        
  • 点大小可调；截图导出当前视角；录制视频默认全景环绕（可勾选跟随航线），右上角 RGB 画中画会一起录进 WebM。
    • 
      

      
场景管理

      
    
        
  • 右上角 场景管理 可以打开、删除或基于原输入重新重建任意已建场景。
    • 
        
  • 删除 只移除该场景的点云缓存，原始上传视频/图片保留；重建 会创建新场景，旧场景不覆盖。
    • 
      

      
视频选帧

      
    
        
  • 均匀选择 支持 2–1000 帧，按视频总帧数生成索引；左上角缩略图只预览 20 个候选，提交时按索引重新抽帧。
    • 
        
  • 模型单次全局 attention 有显存上限：392×700 约 32 帧、518×924 约 19 帧；超出会先均匀降采样，避免 OOM。
    • 
        
  • 选 1000 帧只代表覆盖整段视频，不代表一次推理 1000 帧；常规演示建议 16–32 帧。
    •
